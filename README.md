# A/B Test: Credit Reminder

## 1. Гіпотеза

**Якщо** показати юзерам нагадування в чаті 
коли залишається ≤5 кредитів, **то** конверсія 
в першу оплату зросте, **тому що** нагадування 
створює тригер до покупки в момент коли юзер 
вже відчуває обмеження.

### Чому тестуємо
- Юзери отримують 20 кредитів при реєстрації
- Витрачають їх без першої оплати
- Нагадування з'являється при ≤5 кредитах
- Зникає після першої оплати

---

## 2. Експеримент

### Метрики
| Тип | Метрика | Baseline |
|---|---|---|
| Primary | Conversion Rate | 5.45% |
| Secondary | date_spent_15_credits | — |

### Параметри тесту
| Параметр | Значення |
|---|---|
| MDE | 10% відносний |
| Target CR | 5.99% |
| Confidence | 95% |
| Power | 80% |
| Sample size на групу | 28 477 |
| Мінімальна тривалість | 5 днів |
| Фактична тривалість | 35 днів |

### План дій
- ✅ **Підтверджена** → впроваджуємо для всіх
- ❌ **Спростована** → відкочуємо, шукаємо 
  інші тригери до першої оплати

---

## 3. Результати

### Дані по групах
| Група | Юзерів | Конверсій | CR |
|---|---|---|---|
| A — контроль | 62 479 | 3 498 | 5.5987% |
| B — тест | 62 649 | 3 731 | 5.9554% |
| Різниця | — | — | **+6.37%** |

### Статистика
| Метрика | Значення | Статус |
|---|---|---|
| p-value | 0.0034 | ✅ < 0.05 |
| Z-score | 2.7044 | ✅ |
| Observed Power | 98.51% | ✅ > 80% |
| Confidence | 95% | ✅ |

### Фактичний результат
**Гіпотеза підтверджена ✅**

Конверсія тестової групи вища на **+6.37%**.
Результат статистично значущий — p-value 0.0034 
підтверджує що ефект не випадковий.

**Рішення: впроваджувати фічу.**

### Нові знання
- Нагадування працює як тригер до першої оплати
- Ефект +6.37% нижче MDE 10% — наступного разу 
  брати MDE 5-7% для реалістичнішого планування
- Забруднення контрольної групи 0.14% — 
  допустимо, виключено з аналізу
