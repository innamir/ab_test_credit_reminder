# A/B Test: Credit Reminder — Sample Size & Test Planning

## Мета
Визначити скільки юзерів і днів потрібно 
для надійного A/B тесту.

---

## Параметри розрахунку

| Параметр | Значення | Пояснення |
|---|---|---|
| Baseline CR | 5.45% | Конверсія з історичних даних |
| MDE | 10% відносний | Мінімальний ефект який цікавий бізнесу |
| Target CR | 5.99% | Baseline × 1.10 |
| Confidence | 95% | Alpha = 0.05 |
| Statistical power | 80% | Beta = 0.20 |
| Тип гіпотези | One-sided | Очікуємо лише зростання |

---

## Результат розрахунку

| Метрика | Значення |
|---|---|
| Sample size на групу | **28 477 юзерів** |
| Всього юзерів | **56 954 юзерів** |
| Денний трафік | 6 640 юзерів/день |
| Мінімальна тривалість | **5 днів** |

---

## Перевірка фактичного тесту

| Метрика | Потрібно | Фактично | Статус |
|---|---|---|---|
| Юзерів на групу | 28 477 | 62 568 | ✅ достатньо |
| Тривалість тесту | 5 днів | 35 днів | ✅ достатньо |

---

## Висновок

Фактичний тест перевищує мінімальні вимоги 
по юзерах у 2x, по тривалості у 7x.
Дані достатні для надійного статистичного 
висновку.

> MDE обрано як бізнес-рішення: ефект менше 
> 10% не окупить витрати на підтримку фічі.
